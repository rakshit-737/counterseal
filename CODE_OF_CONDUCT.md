# Code of Conduct

Counterseal is a research project. Contributors, reviewers, maintainers, and
users are expected to make participation respectful, constructive, and safe.

## Expected behavior

- Be respectful, inclusive, and professional.
- Focus criticism on ideas, code, evidence, and decisions rather than people.
- Explain assumptions and welcome good-faith questions.
- Protect credentials, personal data, and private vulnerability reports.
- Accept correction when documentation or implementation claims are not
  supported by evidence.

## Unacceptable behavior

- Harassment, discrimination, intimidation, threats, or personal attacks.
- Sexualized or hostile conduct in project spaces.
- Publishing private information, credentials, or security reports without
  permission.
- Deliberately testing or directing others toward systems outside the declared
  scope.
- Misrepresenting fixture results as production assurance or using the project
  to justify unauthorized changes.

## Enforcement

Report conduct concerns privately to the project maintainers through the
repository hosting service or the private channel provided by maintainers.
Include the relevant context and preserve privacy. Maintainers may remove
content, restrict participation, request remediation, or take other action
appropriate to the situation. Retaliation for a good-faith report is not
acceptable.

This code of conduct applies to project repositories, issue trackers, reviews,
communications, and project-related events.
